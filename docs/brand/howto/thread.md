# How to play — the thread

Copy for the five banners in this directory. One image per post, in order. Do not put all
five in a single post: X collapses them into a grid and the diagrams stop being readable
at that size, which is the only reason they exist.

Every post below is under 280 characters, so this works on a free account. If the account
has Premium there is room to expand — but the short version is not a compromise, it is the
better version. Nobody reads a paragraph on a timeline.

**No hashtags.** They read as reach-buying and this audience discounts them. The images
and the first line are doing the work.

## Notes on the copy

- **Say what it is in the first six words.** "The chart is the level" does more than any
  adjective would. A timeline gives you one line before the reader decides.
- **Every claim is a number the game actually enforces.** 25 seconds, ×10, 25% more, five
  seconds, one hedge. Vague excitement is free, so it is worth nothing; a specific number is
  a promise the game can be checked against.
- **No "revolutionary", no "gamified", no "the future of".** The game is unusual enough to
  describe plainly, and plain description is what reads as confidence.
- **The link goes in post 5, not post 1.** A link in the first post costs reach and, worse,
  asks for the click before anything has been earned.
