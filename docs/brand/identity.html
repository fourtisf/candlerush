Struck, not drawn.

Four marks, all cut from the same candlestick and the same metal. Each one is an object with a light source, a hierarchy and an edge — not a flat icon with the brand colours poured into it. Gold for the candle that closed, green for the one still open.

The material

Three decisions do all the work

Two highlights, one turnMetal is not a colour with a gradient on it. The gold runs light, turns dark at 62%, then catches a second highlight — that turn is the entire difference between gold and yellow.
A ground that liftsThe tile is navy warming toward the top with a gold bloom behind the mark, so the metal has something to sit against. A flat fill leaves it floating.
Green is always nextGold is the candle that closed. Green is the one still open. Every mark in the set holds that, so the logo and the HUD are speaking the same language.

The Vault

Recommended · app icon

One candle struck in gold, the next one already opening in green, and the levels you cleared sunk into the ground behind them.

This is the mark as an object rather than a diagram. The tile is a continuous corner — the same curve an iOS icon uses — filled with a navy that lifts toward the light at the top, so the gold has something to catch on.

The hierarchy is the whole idea. A row of three equal bars is a chart. One hero candle with support behind it and a next move in front of it is a brand.

The Crest

Emblem

A gold shield with the candle cut clean out of it.

Negative space is the oldest premium move there is, and the only one that survives being embossed, embroidered, etched or stamped into anything.

It is the most legible mark in the set — the only one that still reads as a candle at sixteen pixels — because it is two shapes and one hole.

The Signet

Token · avatar

A struck coin: double gold ring, micro-type around the rim, C R with the candle standing in the gap.

The letters never touch the candle — they stand either side of it, so the mark is a monogram and a candlestick at the same time without either one crowding the other.

This is the one to use where the product has to look like money: a wallet row, a chain explorer, a profile picture, a token.

The Wordmark

Type

CANDLE in ink, RUSH in gold, and the word space between them is the candle.

Set in Archivo at weight 900 and width 82 — narrow enough to be dense and heavy enough to hold a metal fill without the gradient collapsing inside the strokes.

The name and the mark are the same object, so the wordmark needs no icon beside it. Use it where an icon would only repeat what the type already says.

Where it goes
Header · title screen · press · one-line brand bar
Watch for
RUSH carries the metal. Never fill CANDLE with it too — two metals in one word is a casino, not a brand.

Usage

Rules worth holding

    Do

  • ✓Clear space equal to the width of one candle body on every side.
  • ✓Swap to the small cut at 32px. It is a separate file for a reason.
  • ✓Keep the light coming from the top left. Every mark here is lit the same way and they only sit together because of it.
  • ✓Use the crest when the mark has to be one colour — it is built from two shapes and a hole, so it survives embossing, etching and embroidery.

    Do not

  • ✕Fill CANDLE with the metal as well as RUSH. Two metals in one word is a casino.
  • ✕Swap green and gold. Gold closed, green is still open — that is gameplay, not decoration.
  • ✕Add an outer glow or a drop shadow to make it carry on a busy background. Change the background.
  • ✕Outline the crest's negative candle. The moment it becomes a ring it reads as a keyhole.
